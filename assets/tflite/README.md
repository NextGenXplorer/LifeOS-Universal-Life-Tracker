# LifeOS - Universal Life Tracker

A futuristic personal life management system with gamification, AI/ML, voice commands, and automation.

## Features

- **Habit Tracking** - Build and track daily habits with streaks
- **Task Management** - Organize tasks with priorities and due dates
- **Expense Tracking** - Log and categorize expenses
- **Goal Setting** - Set milestones and track progress
- **Activity Logging** - Track various life activities
- **RPG Gamification** - Earn XP, level up, unlock achievements
- **AI Insights** - Get personalized recommendations
- **Voice Commands** - Control the app with your voice
- **Automation** - Create IFTTT-style rules

## Getting Started

1. Install dependencies: `flutter pub get`
2. Run the app: `flutter run`

## Tech Stack

- Flutter 3.2+
- Riverpod for state management
- SQLite for local database
- TensorFlow Lite for on-device AI
- Fl Chart for visualizations
