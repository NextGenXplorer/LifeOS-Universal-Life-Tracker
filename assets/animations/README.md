# TFLite Models

This directory contains TensorFlow Lite models for on-device AI/ML processing.

## Models

- `habit_predictor.tflite` - Predicts habit completion probability
- `productivity_model.tflite` - Analyzes productivity patterns
- `mood_forecast.tflite` - Forecasts mood based on habits
- `anomaly_detector.tflite` - Detects unusual patterns
- `insight_model.tflite` - Generates personalized insights

Note: For development, you can use placeholder models. The app includes fallback algorithms when models are not available.
